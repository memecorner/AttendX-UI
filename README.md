# AttendX — Project 38 UI/UX Prototype

Presentation-ready React + Vite UI for **Design and Implementation of a Database Management System for Employee Attendance, Shift and Leave Management System**.

## Included
- Premium HR/workforce dashboard
- Employee CRUD-style screens with search and delete
- Department management
- Shift management and timing validation UI
- Roster preparation UI
- Attendance clock-in/clock-out UI and work-hour concept
- Overtime request + approve/reject flow
- Leave application + approval flow + balance validation concept
- Holiday management
- Reports & analytics
- Responsive layout
- Toasts, modals, validation/error states
- Browser localStorage persistence for the demo

## Run in VS Code
```bash
npm install
npm run dev
```
Then open the Vite localhost URL shown in the terminal.

## Important
This is a frontend/UI prototype with localStorage demo data so it can be presented immediately. The forms are structured so the actions can be connected to the required Python/Java backend and MySQL database later.
